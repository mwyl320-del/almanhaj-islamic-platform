# المنظومة الإسلامية الرقمية الموحدة

تطبيق شامل يهدف إلى توحيد المعرفة الإسلامية في واجهة موثقة وقابلة للتوسع، مع مراعاة:
- التوثيق الكامل للمصادر والمؤلفين والجهات
- الفصل بين المعلومات والرأي والفتوى
- الحفاظ على حقوق النشر
- تنويع المحتوى بين القرآن والحديث والفقه والتفسير والمحتوى التعليمي
- قابلية التوسع عبر المراحل اللاحقة

## هيكل المشروع

- `index.html` — الواجهة الرئيسية
- `style.css` — التنسيقات والهوية البصرية
- `script.js` — منطق التطبيق
- `data/content.json` — بيانات التطبيق
- `manifest.webmanifest` — إعداد PWA
- `sw.js` — خدمة العمل Offline

## التشغيل

افتح الملف `index.html` مباشرة في المتصفح، أو استخدم أي خادم ثابت مثل:

```bash
python -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

## ملاحظات مهمة

- هذه نسخة MVP أولية.
- المحتوى موثق ببيانات مصدرية داخل `data/content.json`.
- لا يُسمح بنشر محتوى غير مرخص أو غير موثوق.
- التوثيق الشرعي والحقلي يُراعى في كل مرحلة لاحقة.
